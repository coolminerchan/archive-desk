# archive-desk v0.7.5

Local interface review build. Not published to GitHub.

The application now separates account backup, saved records, home decoration, and settings. The backup screen focuses on starting or finishing a recording and the latest account's key counts.

- Browse equipment, maps, the Nebula Tree, life professions, social lists, dungeons, and scene records within a single Records section.
- Expand profession cards to see individual skill levels. Optional history and technical evidence remain available without crowding the main view.
- Find manual connection options, capture diagnostics, and recovery tools in Settings.
- Capture, import, archive formats, update verification, and original data preservation are unchanged.

Thanks to the original authors and community contributors listed in the [README](README.md).
