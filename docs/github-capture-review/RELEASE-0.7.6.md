# archive-desk v0.7.6

This release adds clearer saved-data inspection and reorganizes the interface around the backup workflow.

- The home page displays the complete process: start recording, sign in, browse the relevant game pages, finish and save, then inspect results or record missing content.
- Four main sections separate account backup, saved records, home decoration, and settings. Saved records are grouped into equipment, maps, the Nebula Tree, life professions, social lists, dungeons, and scenes.
- Nebula Tree inspection shows recorded pages, active nodes, task progress, and reward claims. Original responses and separate snapshots remain in the archive.
- Life profession cards show individual skill levels separately from profession levels. Verified Chinese skill names are scoped to each profession; unnamed skills retain their IDs.
- Older reports request reanalysis before another recording. Successful empty lists, unconfirmed evidence, and optional history remain distinct.
- Technical evidence, source identifiers, capture timings, and manual connection options are available in expandable sections. Record tabs support keyboard navigation.

Existing account ZIPs can be opened again to expose details already recorded. No new game interaction is required for evidence present in the archive. Observed records do not establish complete map coverage or restored server progress.

The Windows package includes 使用说明.txt and Capture-guide.md. Account capture and archive handling retain the existing preservation behavior.
