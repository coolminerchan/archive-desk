账号采集工具 0.7.0 使用说明
适用于 Windows x64

一、首次运行
1. 完整解压压缩包，再打开「账号采集工具.exe」。不要直接在压缩软件里运行。
2. runtime、resources 文件夹需要与 EXE 放在一起，不要只复制 EXE。
3. 如果没有显示界面，请安装 Microsoft Edge WebView2 Runtime：
   https://developer.microsoft.com/microsoft-edge/webview2/consumer/
4. 实时录制需要管理员权限；只打开已有备份检查数据，不需要提升权限。
5. 本包可独立使用，不需要另外安装服务端管理或游戏启动器。

二、一键采集账号
1. 点击首页「一键采集并打开游戏」，允许系统权限提示。
2. 首次未找到客户端时，选择原版游戏的 launcher.exe 或 Steam 游戏快捷方式。
3. 等工具显示「采集中」后再登录。Windows 采集组件首次加载可能较慢，请等待。
4. 如果游戏已经打开，请返回登录界面重新登录一次，以便取得账号主数据。
5. 按下方清单浏览游戏，等待列表和场景加载后再切换；不用等工具里的每项都变色。
6. 完成后正常退出游戏，工具会自动整理；也可以点击「停止并保存」。
7. 等待整理结束，再打开备份文件夹。识别到唯一账号后才会生成账号 ZIP。

三、游戏内建议浏览的内容
- 角色、穿搭及其分类。
- 背包、仓库、宠物仓库：切换分类并翻页。
- 武器、护甲、装备海报：分别打开完整列表，切换筛选并翻页。只看角色身上的装备不够。
- 世界地图、各已解锁地区的探索页、收集和月亮页面；进入对应地区等待场景加载。
- 自己的家园、各预设、家具和宠物；走到不同区域，等待家具加载。
- 副本入口和已通关记录、成就分组、图鉴、档案、邮件、好友与生活技能。
- 六类生活职业页及各自的图鉴：基础等级、技能、成就和图鉴历史次数分开核对。
- 社交界面的好友、好友申请和黑名单：分别切换并等待加载，保留带分类的列表。
抽卡历史不属于必需采集内容。无需为了采集专门消耗道具、领取奖励或修改装修。

四、单独采集别人家的装修
1. 打开左侧「装修采集」，点击开始录制。
2. 在原版游戏里正常拜访目标家园，走到各个区域等待家具加载，再拜访下一家。
3. 结束后可保存全部装修合集，也可以逐家导出。
账号备份和拜访装修分开保存。此模块不把别人家的装修导入自己的家园。
屋主昵称依赖实际返回的资料；家园编号用于区分归属。无法访问的家园不能通过失败的拜访取得装修。

五、本人场景
完成账号采集后，打开「本人场景」查看已确认归属的场景及物件数量。
可单独导出本人场景 ZIP，也可以打开已有账号包或场景包查看。
同一场景的不同快照分别保留。表格显示信息较多的一份，不会把局部快照拼成最终装修。
独立场景包的归属来自包内索引，不代表重新验证过账号登录。

六、保存位置与核对
账号记录：系统「文档」中的「游戏账号备份」。
装修记录：系统「文档」中的「游戏家园备份」。
设置和错误日志：%APPDATA%\OverField Desktop\capture。
可在「工具设置」打开日志目录，或恢复上次采集重新解析。

导出前会检查文件和归属，复制后核对 SHA-256，成功后才替换目标文件。
登录 UID 与内部角色编号分别保存；缺少登录 UID 时不会用内部编号冒充。
未打开过的列表、未进入的地区和未加载的家具无法据此确认完整。
装备列表与推送可能返回不同来源的物品，列表外已观测装备也会保留，请查看核对结果。
在确认结果前，请保留原始记录；不要把账号包、原始抓包或错误日志直接公开上传。

生活与社交补充说明
旧 ZIP 只有响应、缺少请求头时，工具会保留资料并将分类标为未知。保留原始抓包的，可以重新解析补回已采到的请求分类。
图鉴历史没有回包时，需要打开对应职业图鉴补采。已有等级、技能和成就仍保留，不会从背包数量或成就门槛推算历史次数。
生活基础、图鉴历史、带分类社交列表在界面分别核对。成功空列表与未采到是不同状态。
工具只保留证据，不生成本地账号、家园或好友关系；关系恢复由导入端核对。

七、录制限制与更新
每轮最多录制 30 分钟或约 448 MiB 原始记录，先到上限即开始整理。
如果仍需补充，可另开一次录制。原始记录通常比导出的账号或装修 ZIP 大。
更新前请先结束录制和核对。在「工具设置」检查更新、下载验证并启动新版。
新版使用独立目录，原目录可保留用于回退。尚未公开发行时，更新页可能显示暂无公开版本。

八、遇到问题
- 无法启动：确认完整解压，目录与 EXE 齐全，并检查 WebView2 Runtime。
- 一直没有数据：确认录制已就绪，重新登录原版客户端；必要时在高级采集中识别连接或指定正确范围。
- 缺少部分内容：返回相应列表切换分类、翻页，或走到未加载区域，等待返回后重新保存。
- 采集异常退出：不要删除会话目录，先在工具设置中恢复上次采集。
- 无法保存：更换可写且空间充足的目录，关闭占用目标 ZIP 的程序后重试。
